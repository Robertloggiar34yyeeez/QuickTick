Continues v0.7.5 after user feedback that speed was nearly ideal but scrolling stuttered. v0.7.5 artifacts and release names remain intact.

Home and Favorites cards now fill the available feed width (680-point maximum on tablets), independent of thumbnail dimensions. Bounded image previews fill their cards; View full retains access to the original. Favorites adds immersive paging for images, GIFs and videos without provider pagination. Each completed download has native share-sheet export, including Save to Files where supported. HLS exports retain their original offline package format; no MP4 transcoding is performed.

- Scroll geometry cancels idle intelligence immediately. A single debounce task waits for movement to stop; inference and tail ranking remain deferred. Ranking checks cancellation again before publishing and avoids unchanged array publication. Unchanged interest summaries no longer invalidate the shared SwiftUI store. This addresses avoidable work; physical-device frame pacing still needs user validation.
- Apple Vision feature prints now provide actual normalized visual embeddings, with up to eight independent positive, negative and impression clusters per anime/real-life profile. CPU-only background inference has request cancellation. Vision uses the system framework; WD adds the separately described bundled model. No cloud inference or runtime model download is required. Model revision and per-item analysis revision are persisted.
- Pixel-derived dominant colors, monochrome treatment, luminance/contrast and composition complement metadata attributes and real-life scene classification. Those attributes generalize across subjects; identity remains explicit metadata. Known liked identities are protected from whole-image negative-cluster updates.
- Visual evidence contributes to the existing BGE/tag/diversity ranker and occasionally provides a provider search term. First usable provider results still publish before any ranking. Profile/state decoding accepts the v0.7.5 format.
- Historical favorites use cached previews first. While idle, uncached favorites may fetch one still thumbnail at a time on an inexpensive, unconstrained network, at least three seconds apart, capped at 512 KiB and decoded to 384 pixels. Originals and video streams are never fetched for analysis. Playback, scrolling, pagination, Low Power Mode or thermal pressure cancel/defer analysis. Cached descriptors are bounded to 512; accumulated profiles and analysis ledgers persist.
- Visual taste is enabled unless explicitly disabled in Settings. Its inference remains optional and deferred; metadata/BGE fallback always works. Each historical item remains queued incrementally; uncached/provider-unavailable previews cannot be analyzed until available.

WD ViT Tagger v3 is now included for anime only, pinned to SmilingWolf revision 7f6b584d0bd3f55c4531f14ba3d4761b2bccdc0f. CI converts the original weights to Core ML with float16 weights (int8 variants failed numerical parity), validates synthetic numerical parity, and bundles the compiled model and labels. Swift uses white letterboxing, 448px BGR normalization, conservative general/character confidence thresholds, and separate attribute/identity signals. The model loads only during idle anime analysis and is released after inference. Slow inference introduces a cooldown. Real-life inputs never load WD. Model/source: https://huggingface.co/SmilingWolf/wd-vit-tagger-v3

Every app launch and foreground return queues a visual taste refresh. A fixed-height feed status line reports progress/pauses without blocking first posts or shifting card layout. Existing descriptors are reused; new/changed analysis revisions process historical favorites incrementally.

MobileCLIP2-S0 remains deferred pending conversion/device evaluation; built-in Vision supplies actual visual embeddings now. Exhaustive character, hairstyle, outfit, activity and multi-frame action accuracy is not claimed. Added regressions for real pixel attributes, visual positive/negative/exposure clusters, v0.7.5 profile migration, protected identities, thumbnail-only selection, scroll ranking suppression, and actual Vision encoder output/timing. Existing duplicate, persistence, fallback and playback coverage remains. Local syntax/project checks pass. See CI/final delivery evidence for actual device-test outcomes. No physical-device FPS, memory or time-to-first-frame measurements are claimed.
